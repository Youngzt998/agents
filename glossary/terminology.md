# Terminology (global)

The default term for every concept, across all projects and all kinds of work.
Code, documents, commit messages and conversation use the word recorded here.

`glossary/GLOSSARY.md` is narrower: it holds the writing-specific requirements. An
entry there is either a subset of this file or an override that applies while
writing. Where the two differ, this file is the default and the writing entry wins
inside a writing task.

Format, one entry per concept:

```
### Term
Definition in one or two sentences.
Do not use: synonym1, synonym2
```
