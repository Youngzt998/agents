# Decisions of the author

Reader: the author and every agent of the project, before putting a decision to the author.

An agent about to ask the author for a decision first searches this file; a decision found here is applied, not asked again. A decision the author makes is added here the same day, with its date, one sentence stating it, its scope when given, and its source. The file records the author's decisions only, never the agent's own choices.
