# Paper writing

The general writing rules in `~/.agents/rules/10-writing-docs.md` apply first and
in full. This skill adds what is specific to an academic paper.

Read the file that matches the work in hand:

| Work | File |
|---|---|
| Body prose, related work, citation placement, section boundaries | `~/.agents/skills/paper-writing/prose.md` |
| Naming a concept, defining a term, choosing one vendor's vocabulary | `~/.agents/skills/paper-writing/terminology.md` |
| Authoring or editing a figure, a caption, or a table note | `~/.agents/skills/paper-writing/figures.md` |
| How drafting is paced, what may be edited, when checks run | `~/.agents/skills/paper-writing/process.md` |
| Checking a draft before review or submission | `~/.agents/workflows/paper-quality.md` |

The entry codes P, T and F carry over from the file these rules were written in,
so a correction can be traced to the draft that prompted it. Codes that became
general writing rules live in `rules/10-writing-docs.md` and `rules/30-terminology.md`.
