# Evidence levels (shared, every session, output and thinking)

Every fact you state or rely on carries a level from the table below. Levels run from 0 to 6. Level 0 is the most trusted. Say the level and the source. This applies in the final message, in intermediate messages, and in your own reasoning before you act on a fact.

## The levels

| Level | Meaning | Example source line |
|---|---|---|
| 0 | Machine-checked: a theorem that a proof assistant accepted with no `sorry` or axiom you added; or a settled, well-known algorithm, standard library function, or standard library documentation | "(置信等级-0) Lean theorem `Codec.roundtrip` in `Project/Codec/Proof.lean`, builds clean" / "(置信等级-0) Python `sorted` is stable, per the standard library docs" |
| 1 | Large-scale testing: the behavior held across tens of thousands of inputs or outputs, or a comparable fuzz or differential run | "(置信等级-1) fuzz run, 50,000 seeds, 0 divergences, commit abc123" |
| 2 | Small-scale testing: tens of inputs, a unit test suite, a handful of manual runs | "(置信等级-2) unit tests pass; 12 hand-written cases" |
| 3 | Read the code and reasoned about it, without running it | "(置信等级-3) read `Parser/Grammar.lean` lines 40 to 90" |
| 4 | Read a comment, a doc, a wiki page, or a paper about the code, not the code itself | "(置信等级-4) `docs/design-tenets.md` section 1" |
| 5 | Text that is clearly generated by a language model: an AI-written summary, an AI answer in a chat, an auto-generated doc | "(置信等级-5) earlier AI summary in this session" |
| 6 | Anything weaker: memory, guess, analogy, hearsay, an unverified assumption | "(置信等级-6) I assume the default region is us-west-2" |

The line between level 1 and level 2 is not exact. Tens of thousands of cases versus tens of cases is the usual split. Some systems make even one run expensive, so a few runs can be the best available evidence; say so and still label it level 2.

## How to write it

- Put the level right after the fact, in parentheses, as "(置信等级-N)" in Chinese terminal output and "(confidence level N)" in English artifacts. N is the level number, 0 to 6. Add the source after the number when the reader would otherwise have to ask: "The parser rejects five positional arguments (置信等级-3，读了 parser 的校验函数; 置信等级-2，我写的一个失败测试)".
- Never write bare private codes for a level in terminal output. Private shorthand is for your own reasoning only.
- A fact with two sources gets both levels.
- A fact with no source gets level 6 and you say what would raise it.
- In a work report (`rules/05-terminal-output.md` rule 2), the "overall effect" sentence carries its level.
- In a Terms block, glossary definitions need no level. Claims about behavior always do.

## How to use it when deciding

- Before you act on a fact that would cost the user time if wrong (deleting, refactoring, reporting a result), check its level. Level 3 or higher (less trusted) means: run something to raise it, or tell the user you are acting on unverified reading.
- Never let a level 5 or level 6 fact silently upgrade by being repeated. Repetition does not add evidence.
- When two facts conflict, the lower level number (more trusted) wins. Report the conflict.
- Never write "proven", "verified", "guaranteed" for anything other than level 0. Never write "tested" for anything at level 3 or higher.
